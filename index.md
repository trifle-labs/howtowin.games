# Game Index

All games in the archive, grouped by family. Solution status uses the
[Allis hierarchy](README.md#what-solved-means):

- **Strong** — strongly solved (optimal play from every position)
- **Weak** — weakly solved (optimal play from the start)
- **Ultra-weak** — ultra-weakly solved (value known, strategy not)
- **Partial** — solved only for some board sizes / positions
- **Unsolved** — game-theoretic value of the standard game is unknown

"Value" is the game-theoretic value of the standard initial position with
perfect play. An asterisk (\*) means the value depends on the starting position
(typical of Nim-like games). **[verify]** flags a result the archive author has
not confirmed against a primary source.

See also: [Lexicon](lexicon/README.md) · [References](references.md)
