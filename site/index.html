about this search

This is a semantic search over the howtowin.games corpus (… games, … references, … lexicon terms). Both the database and the embedding model run in your browser — nothing is sent to a server.

Query embeddings: BAAI/bge-small-en-v1.5 via transformers.js (ONNX, ~30 MB, cached after first load). Vector search: sqlite-vec WASM running the same howtowin.db the CLI uses (download).
